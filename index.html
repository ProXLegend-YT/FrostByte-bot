Getting Started

Three steps. That's it.

1

Add Frostbyte to Discord

Tap "Add to Discord" below. Discord opens its own screen where you pick which of your servers to add the bot to — nothing happens on this site.

2

Come back and open the Dashboard

Once the bot's in your server, return here and tap "Open Dashboard." Log in with Discord — this is Discord's own secure login, we never see your password.

3

Pick your server and configure

After logging in, choose your server from the list. You're straight into the control panel — set up moderation, economy, tickets, and everything else.

How adding Frostbyte actually works

Clicking "Add to Discord" takes you to Discord's own official page for adding a bot — Frostbyte never asks for your Discord password or any personal information at that step. You'll need the Manage Server permission on whichever server you want to add it to; if you don't have that permission, ask whoever owns or manages the server to click the link instead.

Once the bot is in your server, you can start using it two ways: type / in any channel to use its 78 slash commands directly in Discord, or open the web Dashboard for a visual control panel — no commands to remember, just click through settings for moderation, tickets, the economy system, automod, and more.

The Dashboard login is separate from adding the bot — it's just you signing in with your own Discord account (the same official Discord login screen you already trust) so the site knows which of your servers you're allowed to manage. If a server doesn't show up in the picker, it's usually because the bot hasn't been added there yet, or you don't have Staff/Admin permission on it.
